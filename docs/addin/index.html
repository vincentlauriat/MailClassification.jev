Highlighted: what runs on your computer.En surbrillance : ce qui tourne sur votre ordinateur.醒目標示：在你電腦上執行的部分。

  • Served by your own server. jevoutlook ui serves the dashboard on http://127.0.0.1:5177 and the pane on https://localhost:5178, with the ASP.NET Core development certificate. If it is not running, Outlook has nothing to load.Servi par votre propre serveur. jevoutlook ui sert le tableau de bord sur http://127.0.0.1:5177 et le volet sur https://localhost:5178, avec le certificat de développement ASP.NET Core. S'il ne tourne pas, Outlook n'a rien à charger.由你自己的伺服器提供。jevoutlook ui 在 http://127.0.0.1:5177 提供儀表板，並以 ASP.NET Core 開發憑證在 https://localhost:5178 提供窗格。它沒在執行時，Outlook 就沒有東西可載入。
  • No sign-in of its own. The add-in reuses jevOutlook's Microsoft 365 sign-in and stored key, with the first signed-in Microsoft 365 mailbox. The message is found with convertToRestId, then read through Microsoft Graph.Aucune connexion propre. Le complément réutilise la connexion Microsoft 365 et la clé enregistrée de jevOutlook, avec la première boîte Microsoft 365 connectée. Le message est retrouvé via convertToRestId, puis lu par Microsoft Graph.本身不需登入。增益集沿用 jevOutlook 的 Microsoft 365 登入與已儲存的金鑰，使用第一個已登入的 Microsoft 365 信箱。郵件先以 convertToRestId 定位，再透過 Microsoft Graph 讀取。
  • Locked to your machine. Loopback only; any other Host header gets 421; the API answers same-origin JSON POST requests only. Email content is shown as text, never as HTML.Verrouillé sur votre machine. Boucle locale seulement ; tout autre en-tête Host reçoit 421 ; l'API ne répond qu'aux requêtes POST JSON de même origine. Le contenu des e-mails est affiché comme texte, jamais comme HTML.鎖定在你的電腦上。只監聽本機回送位址；其他 Host 標頭一律回 421；API 只接受同源的 JSON POST 請求。郵件內容以純文字顯示，絕不當成 HTML。

InstallInstaller安裝

Seven steps to a working paneSept étapes jusqu'au volet七個步驟完成安裝

macOS / Linux syntax. On Windows PowerShell, use $HOME\.jevoutlook\bin for ~/.jevoutlook/bin.Syntaxe macOS / Linux. Sous Windows PowerShell, utilisez $HOME\.jevoutlook\bin à la place de ~/.jevoutlook/bin.以下為 macOS / Linux 語法。在 Windows PowerShell 中，請把 ~/.jevoutlook/bin 換成 $HOME\.jevoutlook\bin。

  1. Build and publishCompiler et publier建置並發佈

    A stable copy in ~/.jevoutlook/bin; put it on your PATH.Une copie stable dans ~/.jevoutlook/bin ; ajoutez-la à votre PATH.在 ~/.jevoutlook/bin 產生穩定的副本，並加入 PATH。

    git clone https://github.com/vincentlauriat/MailClassification.jev.git
cd MailClassification.jev
dotnet publish src/JevOutlook -c Release -o ~/.jevoutlook/bin

  2. Store the OpenRouter keyEnregistrer la clé OpenRouter儲存 OpenRouter 金鑰

    Store it even if your shell exports it: the background service does not see shell variables.Enregistrez-la même si votre shell l'exporte : le service d'arrière-plan ne voit pas les variables du shell.即使 shell 已經匯出也要儲存：背景服務看不到 shell 的環境變數。

    jevoutlook key set sk-or-...
jevoutlook key test

  3. Connect the Microsoft 365 mailboxConnecter la boîte Microsoft 365連接 Microsoft 365 信箱

    After the one-time Entra app registration; then type the device code that is printed.Après l'inscription Entra unique ; saisissez ensuite le code affiché.先完成一次性的 Entra 應用程式註冊，再輸入畫面上顯示的裝置代碼。

    jevoutlook config set client-id <application-client-id>
jevoutlook account add alice@contoso.com --m365

  4. Trust the development certificateApprouver le certificat de développement信任開發憑證

    Once per computer. Outlook only loads add-in pages over HTTPS.Une fois par ordinateur. Outlook ne charge les pages de complément qu'en HTTPS.每台電腦一次。Outlook 只透過 HTTPS 載入增益集頁面。

    dotnet dev-certs https --trust

  5. Keep the server runningGarder le serveur en marche讓伺服器持續執行

    macOS: a LaunchAgent starts it at login; service status should report Health : jevOutlook … answers. Windows / Linux: no service command yet — run jevoutlook ui --no-open and keep it running, for example as a scheduled task at logon.macOS : un LaunchAgent le lance à l'ouverture de session ; service status doit afficher Health : jevOutlook … answers. Windows / Linux : pas encore de commande service — lancez jevoutlook ui --no-open et gardez-le en marche, par exemple via une tâche planifiée à l'ouverture de session.macOS：由 LaunchAgent 在登入時啟動；service status 應顯示 Health : jevOutlook … answers。Windows / Linux：目前還沒有 service 指令——請執行 jevoutlook ui --no-open 並保持執行，例如設成登入時的排程工作。

    jevoutlook service install --exe ~/.jevoutlook/bin/jevoutlook
jevoutlook service status

  6. Check the pane in a browserVérifier le volet dans un navigateur在瀏覽器中檢查窗格

    Open https://localhost:5178/taskpane.html. It must load with no certificate warning and show your mailbox in its header.Ouvrez https://localhost:5178/taskpane.html. La page doit se charger sans avertissement de certificat et afficher votre boîte dans son en-tête.開啟 https://localhost:5178/taskpane.html。頁面必須在沒有憑證警告的情況下載入，並在頂端顯示你的信箱。

  7. Get the manifestRécupérer le manifeste取得資訊清單

    Download https://localhost:5178/manifest.xml, or write it with the CLI (without --out it goes to release/jevoutlook-manifest.xml under the current directory; --https-port if you changed the port).Téléchargez https://localhost:5178/manifest.xml, ou écrivez-le avec la CLI (sans --out, il va dans release/jevoutlook-manifest.xml sous le répertoire courant ; --https-port si vous avez changé le port).下載 https://localhost:5178/manifest.xml，或用命令列產生（沒有 --out 時會寫到目前目錄下的 release/jevoutlook-manifest.xml；若改過連接埠請加 --https-port）。

    jevoutlook addin manifest --out ~/jevoutlook-manifest.xml

StatusÉtat現況

What works today, and what does not yetCe qui marche aujourd'hui, et ce qui pas encore目前可用與尚未完成的部分

⚠
Sideloading in a real Outlook is not validated end to end yet. The pane works in a browser and the manifest passes Microsoft's validator, but the one sideload attempt so far was on a corporate tenant that blocks custom add-ins. The pane needs the local server running (option 1); an on-demand start (option 2) is designed, not built. Microsoft 365 and Outlook.com only, and always the first signed-in Microsoft 365 mailbox. Le chargement dans un vrai Outlook n'est pas encore validé de bout en bout. Le volet fonctionne dans un navigateur et le manifeste passe le validateur de Microsoft, mais la seule tentative à ce jour visait un tenant d'entreprise qui bloque les compléments personnalisés. Le volet a besoin du serveur local en marche (option 1) ; un démarrage à la demande (option 2) est conçu, pas construit. Microsoft 365 et Outlook.com seulement, et toujours la première boîte Microsoft 365 connectée. 在真正的 Outlook 中側載尚未完成端到端驗證。窗格在瀏覽器中運作正常，資訊清單也通過 Microsoft 驗證工具，但目前唯一一次側載嘗試是在封鎖自訂增益集的企業租用戶上。窗格需要本機伺服器持續執行（方案一）；隨需啟動（方案二）已完成設計、尚未實作。僅支援 Microsoft 365 與 Outlook.com，且一律使用第一個已登入的 Microsoft 365 信箱。
